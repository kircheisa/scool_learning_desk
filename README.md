# 知谱 · 小学诊断辅导平台

基于开源知识图谱 **cn-math-taxonomy** 构建的前端诊断辅导平台。核心能力：**沿先修关系回溯，找到真正没学会的前置知识点，并给出补学路径**。

## 打开方式

- **最简单**：双击 `index.html`（现代浏览器即可，数据以内联 JS 形式加载，无需构建）
- **本地服务器**（推荐）：在本目录运行 `python -m http.server 8765`，浏览器访问 `http://127.0.0.1:8765`
- 整个目录自包含，复制到任意位置后仍可独立运行（所有资源用相对路径，无需构建、无需联网）
- 错题里的科目 / 年级取自题目所属知识点；老版本错题记录会在对应学科加载后自动补齐标签
- 错题归因遵循「孩子自己归类、遮答案重做、只练高频类、做对归档」：AI 不代判错因、不推变式题海、不给正确率或排名。记录只用于安排练习，不用于评价孩子

## 功能

| 页面 | 说明 |
|---|---|
| 首页 | 四学科入口与真实数据统计 |
| 知识图谱 | 按学科 / 年级 / 章节浏览知识点，查看先修与后续关系；可把当前范围导出为 **Mermaid / Markmap** 供备课分享 |
| 开始诊断 | 按年级册次或指定知识点；指定模式可选年级直接列出该年级知识点，再叠加关键词搜索、多选，支持深度诊断（含前置回溯）与年级筛查；**图形题显示内联 SVG 配图**（科学 19 道原生图 + 数学 36 道按题干生成的观察物体/几何示意图，浅色纸面卡片呈现） |
| 诊断报告 | 根因定位、掌握 / 不稳 / 薄弱统计、按顺序的补学路径；新增「接下来怎么做」可观察表述（能独立做出 / 卡在哪一步 / 下一步练什么），可导出 Markdown |
| 错题本 | 答错的题自动收录，本机保存；带**科目 / 年级标签**，按科目、年级、错因筛选；**先遮住答案自己做一遍**再揭晓正确项与误选项文字及解析；图形题同时显示配图；孩子自标四类错因、做对归档；**归因闭环**：全部/本周分布看板、高频错类（≥3 次）标出并给一句行动结论、一键「只练这一类」（最多 5 道）；分布只给中性计数，不打分不排名 |
| 组卷 | **双向细目表组卷**：选年级 / 知识点 / 题量 / 难度配比（易:中:难）→ 生成知识点 × 难度矩阵（行列合计严格相等）→ 按格抽题 → **在线答卷**（选择题点选、填空题输入、交卷批改、逐题显示答案与解析、得分统计、答错自动进错题本、可再答一次）或导出可打印 HTML 练习卷（题目 + 答案分页）。题库某难度不足时如实标注降级，正式使用请教师审核 |

## 诊断规则（沿用原仓库引擎）

- 每个知识点需**连续答对 N 题**（可选 2/3/5）才判为「掌握」，并推断其先修祖先已掌握。
- 答错后先出一道更基础的确认题：
  - 确认题答对 → 判为「不稳」，不回溯。
  - 确认题答错 → 判为「薄弱」，并把它的先修（hard 优先于 soft）压入出题栈继续追溯。
- 题量用完时若还有未结论的点，报告会标注「还有更前置的点没测到」，可加大题量重测。
- 学习进度选「上半」时，本年级下册知识点视为「还没学」，不会误判为薄弱。
